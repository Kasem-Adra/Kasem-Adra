### Adaptive Cognitive Orchestration for Resource-Constrained Local Language Models (ACO-LLM)

*A Contract-Driven Research Protocol with Formal Guarantees and Reference Implementation.*

ACO-LLM investigates adaptive orchestration strategies for improving the reliability and resource efficiency of local language models through structured task contracts and evidence-based validation.
